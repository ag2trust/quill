# Quill Proof of Concept Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `quill exec`, a headless, stateless coding-agent CLI that runs one Claude-driven task per process and reports the outcome as JSON lines.

**Architecture:** A `cmd/quill` entry point wires small internal packages: CLI parsing, a JSONL event writer, a caller-owned session file, workspace-confined tools, a process-group runner for shell commands, a Claude client with typed errors, and the agent loop that ties them together. History is kept as raw JSON and replayed byte-for-byte, so prompt caching survives across steps and across resumed runs.

**Tech Stack:** Go 1.26, `github.com/anthropics/anthropic-sdk-go/v2` (only third-party dependency), standard library otherwise.

**Spec:** `README.md`, section "Decided". Open items are in `DISCUSSION.md`; this plan decides several of them (marked "decides DISCUSSION x.y").

## Global Constraints

- Module path `quill`. Go 1.26. `CGO_ENABLED=0`.
- One third-party dependency: `github.com/anthropics/anthropic-sdk-go/v2`, pinned to an exact version in `go.mod`. Use `syscall` (not `x/sys`) for `Setpgid`, `Kill`, `Flock`.
- Must build for `linux/amd64`, `linux/arm64`, `darwin/arm64`. Unix only; no Windows.
- stdout carries only JSON lines. stderr carries human diagnostics only, and never prompts, file contents, or secrets.
- API key only from `ANTHROPIC_API_KEY`, passed explicitly with `option.WithAPIKey`. Base URL from `ANTHROPIC_BASE_URL` when set (used by tests).
- Never send `temperature`, `top_p`, `top_k`, or `thinking` (Opus 5.5 rejects disabling thinking; adaptive is the default).
- Every request sends top-level `cache_control: {"type":"ephemeral"}` (automatic caching).
- History, system prompt, and tool definitions are sent as stored raw JSON, never re-encoded.
- Defaults (decides DISCUSSION 2.2): `--max-steps 100`, `--max-tokens 2000000` (counts input + output + cache_write, not cache_read), `--timeout 30m`. Per-request output cap `max_tokens: 32000`. Shell command timeout 10 minutes. Tool output cap 30,000 bytes.
- Exit codes: 0 completed, 1 internal_error, 2 bad usage, 3 limit_reached, 4 provider_error, 5 blocked, 143 cancelled.
- Tests never call the real API unless built with `-tags live` and `QUILL_LIVE=1`.

## Review Focus

1. A shell command that leaves a background process (`sleep 600 &`) must return promptly; the background process dies at run end. Test in Task 6.
2. A session file whose last line was cut off by a crash must still resume, ignoring the partial line. Test in Task 7.
3. A command with endless output (`yes`) must not grow memory without bound and must truncate deterministically. Test in Task 3 and Task 6.
4. A symlink inside the workspace pointing outside it must be refused for read, write, edit, list, and search. Test in Task 3.
5. Resuming a session cancelled mid-tool (last message is an assistant `tool_use` with no results) must produce a valid request, not an API 400. Test in Task 8.
